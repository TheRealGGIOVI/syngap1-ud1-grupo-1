## 📖 Descripción del Proyecto

Este repositorio contiene el código fuente, la documentación técnica y la resolución de actividades desarrollada por el **Grupo 1** para la **Unidad Didáctica 1 (UD1)**. 

El propósito central de este proyecto es aplicar los conceptos fundamentales del módulo de forma rigurosa, garantizando una arquitectura limpia, un control de versiones eficiente y una documentación profesional orientada a la evaluación.

> [!NOTE]
> Este proyecto cumple estrictamente con el flujo de trabajo colaborativo en **Git/GitHub**, buenas prácticas de desarrollo de software y estándares de documentación técnica.

## 🌿 Estrategia de Ramas (Git Flow)

El proyecto utiliza una estructura de ramas organizada para mantener la estabilidad del código en `main`:

```text
main (producción / entregable final)
 └── development (integración del equipo)
      ├── Gio (rama de desarrollo de Giovanni)
      ├── Pablo (rama de desarrollo de Pablo)
      └── Paco (rama de desarrollo de Francisco)
```

> [!TIP]
> Cada participante desarrolla sus cambios en su rama individual antes de realizar una Pull Request hacia `development`.

## 🚀 Instalación y Requisitos

### Prerrequisitos

Asegúrate de contar con el siguiente software instalado en tu sistema:

- [Git](https://git-scm.com/) (v2.30 o superior)
- Editor de código recomendado: [Visual Studio Code](https://code.visualstudio.com/)

### Pasos para Clonar y Ejecutar

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TheRealGGIOVI/syngap1-ud1-grupo-1.git
   ```

2. **Acceder a la carpeta del proyecto:**
   ```bash
   cd syngap1-ud1-grupo-1
   ```

3. **Cambiar a la rama de desarrollo:**
   ```bash
   git checkout development
   ```

4. **Abrir en tu editor de código:**
   ```bash
   code .
   ```
