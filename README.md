## 📖 Descripción del Proyecto

Este repositorio contiene la solución, documentación y código fuente desarrollados por el **Grupo 1** para la **Unidad Didáctica 1 (UD1)**. El objetivo principal es aplicar los conceptos fundamentales aprendidos durante el módulo, garantizando un desarrollo estructurado, limpio y colaborativo.

> [!NOTE]
> Este proyecto sigue las buenas prácticas de desarrollo de software, control de versiones mediante Git/GitHub y documentación profesional para facilitar su evaluación.
